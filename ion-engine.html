In Development

Ion Engine

The workshop behind our games. Every title we ship teaches us something about the tools we wish we had — Ion Engine is us building them properly.

  • Status: in development
  • Public build: not yet
  • Early access: planned
Why An Engine?

Tools shaped by real games

Most tools force a trade-off between speed and control. We'd rather not choose. So alongside every game we ship, we're building our own — shaped by what we actually needed on real projects, not a features checklist.

Ion Engine is where the lessons from those games go next.

                    Design Goals
                    
What we're building toward

                    
These are goals, not shipped features. We'll mark each one as it becomes real.

                

                

                    

                        
                        Goal
                        
Game feel first

                        
Juice, timing and feedback treated as core systems — the tiny shake, the coin pop, the combo window — not afterthoughts.

                    

                    

                        
                        Goal
                        
Fast iteration

                        
Change a number, see it in the game. The shorter the loop between idea and playtest, the better the game gets.

                    

                    

                        
                        Goal
                        
Mobile & web

                        
Built for the platforms we actually ship on, and tuned to run smoothly on everyday phones, not just dev machines.

                    

                    

                        
                        Goal
                        
Tycoon toolkit

                        
The systems every idle game needs — economies, upgrades, offline earnings — as reusable building blocks.
